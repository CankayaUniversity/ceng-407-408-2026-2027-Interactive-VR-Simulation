# Report cover asset

`cankaya-university-logo.png` is the Çankaya University mark, extracted without
redrawing from the first page of the user-supplied prior CENG 407 report
`Literature & Related Work.pdf` (Helma AI, dated 29 November 2025).

It is used here solely to identify the university on this team's academic report.
The mark remains associated with its university; this use does not designate the
report layout as an official university template. Prior students' names, report
text and project content are not incorporated into the cover.
