# Ortam kartı önizlemeleri

Bu JPEG dosyaları mevcut uygulamada yüklenen gerçek GLB modellerinin ekran görüntüleridir. Stok veya üretilmiş görsel değildir; Dashboard üzerinde Babylon motoru başlatılmaz.

- `b737-cockpit.jpg` / `b737-cockpit-640.jpg`: registry kimliği `b737-cockpit`, mevcut Boeing 737-800 GLB. Kokpitin ön paneli ve orta konsolu.
- `charite-operating-room.jpg` / `charite-operating-room-640.jpg`: registry kimliği `charite-operating-room`, mevcut Charité GLB.
- Büyük dosyalar 1200×675, küçükler 640×360, JPEG kalite 82. Sırasıyla 94.733 / 39.676 ve 81.986 / 33.709 bayt.

Yenileme: ilgili ortamı uygulamanın mevcut kartından açın, gerçek model yüklemesini bekleyin; uygun kamerayı yalnız oturum içinde ayarlayın. Ekran görüntüsünü viewport içeriğine kırpın, editör panellerini çıkartın, 16:9 oranında yukarıdaki iki boyuta dönüştürün. Kaydetme işlemi için zone veya proje oluşturmak gerekmez. Modelin kendisi ve kayıtlı kamera verisi değiştirilmez. Kart yolları registry `id` değerinden türetilir; yeni kimlik için aynı dosya adlandırmasını kullanın.

Charité model kaynağı: Digital Surgery, [Sketchfab modeli](https://sketchfab.com/3d-models/charite-university-hospital-operating-room-fa63aa330e1048a7ab7e63a54845c6c3), [CC-BY-NC-4.0](https://creativecommons.org/licenses/by-nc/4.0/). Atıf registry verisinden kart üzerinde de gösterilir. Diğer model için mevcut varlık belgeleri geçerlidir; bu önizlemeler yeni bir lisans hakkı tanımlamaz.

Görsel isteği başarısız olursa kart, “Preview unavailable” açıklaması olan sakin bir yer tutucu gösterir; mevcut ortam açma düğmesi kullanılabilir kalır.
