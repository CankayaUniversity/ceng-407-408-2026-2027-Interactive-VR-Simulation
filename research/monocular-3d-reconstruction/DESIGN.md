# Design System: Monocular 3D Reconstruction Research

## Overview
An English academic/open-source showcase, using deep blue editorial plates, generous figures and qualified experimental claims.
The delivered surface is the root GitHub README, not a deployed application. GitHub controls document fonts, theme, content width, links and native Markdown components. Custom design lives primarily inside SVG figures.

## Colors
Navy anchors hero/timeline plates; light text supplies hierarchy.
Blue and teal distinguish camera pipelines. Ochre identifies the blur-aware alternative; pale blue identifies a baseline.
Series colors are not universal success/failure states. Method labels, values, units and captions carry every comparison independently of color.
Quantitative figures use a white ground and dark labels for readability across surrounding themes.

## Typography
SVG figures use Arial with a sans-serif fallback. Hero/timeline sizes are intrinsic SVG units and scale with the image.
Native headings, prose, code and links use GitHub typography. Preview system fonts and Consolas are review styles, not GitHub overrides.
Keep meaningful alternatives and repeat consequential findings in adjacent text. Proportional scaling does not guarantee small-text legibility on narrow screens.

## Layout
One reading column: motivation, experimental sequence, evidence, turning point, findings, future proposal, detailed references.
Full-width figures and semantic headings establish hierarchy. In-page links provide navigation; optional details hold secondary explanation.
Mermaid uses top-to-bottom flow so labels remain legible within a document column.
The local preview caps its container at1012px with44px desktop padding; below700px it uses22px vertical/18px horizontal padding. These values describe the preview only.

## Shapes and depth
Custom figures are flat rectangular plates. Dashed reserved panels use subtle4px corners and clearly identify missing unapproved imagery.
Charts use simple bars/axes. No decorative shadow, animation, application card or custom control system is shipped.

## Components
- Hero and research timeline: typographic SVG plates, descriptive titles and Markdown alternatives.
- Reserved experiment panels: conspicuous labels, intended evidence named, no simulated reconstruction.
- Quantitative figures: real aggregate measurements, series labels/units and limitations. Sources in data/; hashes/types in assets/PROVENANCE.json.
- Native Markdown: headings, links, callout, details/summary and Mermaid. No independent frontend component library.

## Do and do not
Keep comparisons and caveats together. Preserve keyboard-accessible native links/disclosures and descriptive alternatives.
Check actual reading-width text before publishing. Record provenance for subsequently approved images.
Never treat a placeholder as experimental evidence or publish a room visual without exact-image review.
Never imply preview CSS controls GitHub, or present proposed integration as implementation.
